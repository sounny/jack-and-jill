# AGENTS.md

## Project

This repository contains the Jack and Jill educational reading game.

## Structure

- Keep the main game in `index.html` at the repository root.
- Keep the project simple and suitable for GitHub Pages.
- Do not add the user's reference image to the repository. It is reference material only.

## Game Design

- The game should be child-friendly and touch-friendly.
- Reading and learning should be central to the experience.
- Use clear text, large controls, and simple interactions.
- Voice reading and word highlighting may be used when appropriate.
- Avoid unnecessary external dependencies.

## Technical Rules

- Prefer a self-contained `index.html` when practical.
- Use HTML, CSS, and JavaScript that can run as a static GitHub Pages site.
- Do not expose API keys, passwords, tokens, or other secrets.
- Test the game on both desktop and mobile-sized screens.
- Preserve working features when making changes.

## GitHub Pages

The repository uses the `main` branch. The intended Pages source is the repository root, with `index.html` as the entry point.

## Commits

Use clear, concise commit messages that describe the change.
