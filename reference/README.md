# Reference Image

This folder is for the reference artwork used to guide development of the Jack and Jill learning game.

## What we are building

We are creating an interactive reading and learning game based on the nursery rhyme **Jack and Jill**.

The game is designed for children and focuses on:

- Reading the rhyme
- Listening to the rhyme being read aloud
- Following each word as it is spoken
- Learning new words through pictures and sounds
- Matching pictures or emojis to parts of the rhyme
- Building and ordering sentences
- Retelling the story
- Using large, simple, touch-friendly controls

## How the reference artwork is used

The reference image shows the visual style and story setting we want to use for the game. It helps guide the characters, hill, house, well, bucket, landscape, and overall child-friendly scene.

The artwork is a reference for development. The main game should remain functional without depending on this image unless we intentionally add it as a game asset.

## Repository structure

The main game is kept in `index.html` at the root of the repository so it can work easily with GitHub Pages.

The `reference/` folder is separate from the main game. It keeps reference material organized and prevents reference artwork from being treated as a required game asset.

## Current game features

The current prototype includes the Jack and Jill rhyme, read-aloud controls, word highlighting, word pronunciation, emoji-based learning activities, feedback, progress tracking, and a responsive layout for computers and touch devices.

## Important note

Do not delete or replace the reference material without checking how it is being used in the design process. The reference artwork should not be treated as the source code or as a required dependency of the game.
